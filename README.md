# Sea Urchin Surf House

Static site for Sea Urchin Surf House (Ericeira, Portugal), served from GitHub
Pages at [seaurchinsurfhouse.com](https://seaurchinsurfhouse.com), DNS on
Cloudflare.

Originally migrated off Squarespace as a raw `wget` mirror, then fully
rebuilt as hand-authored HTML/CSS — no Squarespace framework code remains.

## What's here

- `*.html` — one file per page, generated by `build.py`
- `assets/style.css` — the entire site stylesheet (tokens, layout, components)
- `assets/nav.js` — mobile nav toggle (the only JS on the site)
- `assets/img/` — real, right-sized site photography
- `build.py` — the actual editable source. Page content, copy, pricing, and
  the shared header/nav/footer all live here as data + template functions.

## Editing content

Don't hand-edit the generated `*.html` files — edit `build.py` (the `UNITS`,
`SPACES`, `SPOTS` lists, or the `build_*()` functions for one-off pages),
then regenerate:

```
python3 build.py
```

This overwrites all 15 HTML files from the templates. Commit the results.

## Design system

Tokens and component rationale (colors, button/card/frame treatment) are
documented in the design review: ask Claude, or see the `theme.css` commit
history for the original audit this was built from.

## Known gaps

- No real booking/contact form — the original site only ever offered an
  email address for reservations, so that's what's here too
  (`mailto:seaurchinsurfhouse@gmail.com`).
- No CI — `build.py` is run locally and its output committed directly.
